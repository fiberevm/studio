- **Secrets.** Agents use API keys, tokens and passwords by name without seeing them. A session asks for one and you type it into a Studio panel; commands get it as an environment variable, and Studio scrubs it from their output. Each secret can expire. Manage them in Settings → Secrets.
- **Settings → Worktrees** lists every worktree with its size, its changes and the sessions using it, and deletes one or cleans up all the unused ones.
- **Panes close by themselves** when their last tab closes (Settings → Sessions).
- **Windows come back as you left them:** only the windows that were open, at their size and place.
- File tabs follow theme changes.
- Settings use Studio's own switches, with every control aligned on the right.
- Snippets are removed.
