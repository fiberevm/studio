- **Workers:** run sessions on your other machines (a Linux box or Mac on Tailscale, Cloudflare Zero Trust or your LAN) and see them in tabs like local ones.
- **The + menu:** a session for each installed agent, a terminal, a web browser and sessions on workers, each with its shortcut.
- **⌘K quick switcher** for the project's open sessions; the quick prompt moves to ⇧⌘K.
- **Faster new tabs:** agent CLIs start directly instead of through a login shell.
