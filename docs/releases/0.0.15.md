- **A download less than half the size.** Studio now comes as two builds, one for Apple silicon (M1 and later) and one for Intel, instead of one app holding both. The download goes from 9.6 MB to about 4 MB. Pick yours from the website or the release; an installed copy updates itself to its own Mac's build.
- **Telemetry counts sessions and tokens.** Anonymous usage events now include each agent tab that opens (which agent, and whether it's new, resumed, forked or restored) and how many tokens Studio's sessions processed, per agent. Still no prompts, code, output, names or paths. Turn it off in Settings → Telemetry.
