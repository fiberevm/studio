- **Check for Updates is always available** and opens Studio's own update window, in your theme: it says when you're up to date, shows a new version's download progress, and installs it right away with Install Now (or later).
- **Settings → Updates** lists every release with what changed, and can install any of them, including an earlier version to go back to. Its signature is checked first, and your sessions keep running.
- **Anonymous telemetry** helps us improve Studio: a random install id, the app and macOS versions, and when Studio opens or a session starts. Never your code, prompts, names or paths. Turn it off in Settings → Telemetry or on the welcome window.
