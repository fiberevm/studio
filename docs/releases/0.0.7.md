- **In-app updates.** Studio checks for new versions about once a day, downloads them in the background and installs them when you quit.
- **A worktree per session.** In a git repo, each new session starts in its own git worktree, so agents working in parallel don't edit the same files. Untouched worktrees are removed when their session ends.
- **File editor.** ⌘K also finds the project's files and opens them in an editor tab: syntax colours, line numbers, ⌘S, ⌘F, and live reload when an agent edits the file.
