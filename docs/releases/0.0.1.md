The first release of Studio: a Mac workspace for running many Claude Code sessions at once.

- **Sessions in tabs and splits.** The real `claude` CLI in real terminals, one window per project, with a sidebar of what's waiting for you.
- **Web panels.** Open a page in a tab or split beside your sessions; agents can read, click, type and screenshot it through the Studio MCP.
- **Studio MCP.** Every session can drive the editor: open splits, start sessions, run commands in a terminal beside it.
- **Sandboxes.** Run work in remote Linux machines on boat.dev or AWS Lambda MicroVMs.
- Universal build (Apple silicon and Intel), signed and notarized.
