- **Your sessions stay in the right window.** A session whose window was closed now goes back to its project's window when Studio restarts, instead of waiting for the closed window and leaving the project window empty.
- **A session is only ever in one window.** A window on your home folder no longer takes other windows' tabs.
- **No empty panes after a restart.** With "Close a pane when its last tab closes" on, panes that were left empty don't come back.
